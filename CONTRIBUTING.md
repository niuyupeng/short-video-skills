# 贡献指南 / Contributing

## 中文
### 提交新 skill 或改进已有 skill
1. 新 skill 放在 `skills/<skill-name>/SKILL.md`，名称用小写加连字符。
2. frontmatter 必须有 `name` 和 `description`；description 只写「什么时候用」。
3. 正文尽量少于 500 行，给出可执行步骤和自检清单。
4. 改进已有 skill 时，在 PR 里说明改了什么、为什么改，最好附一个前后对比例子。

### PR 规范
- 一个 PR 只做一件事；标题格式：`feat(skill-name): ...` / `fix(skill-name): ...` / `docs: ...`。
- 不转载他人受版权保护的内容，参考外部项目请只给链接。
- 提交即表示同意以 MIT 许可证发布你的贡献。

### 隐私红线
不要收录任何隐私或敏感内容：真实姓名、账号名、联系方式、本机路径、真人照片、未公开的内部资料、API key / token / 密码。含有这些内容的 PR 不会被合并。

## English
### Adding or improving a skill
1. Put new skills in `skills/<skill-name>/SKILL.md` (lowercase, hyphenated).
2. Frontmatter must include `name` and `description`; the description states only when to use it.
3. Keep the body under ~500 lines with actionable steps and a self-check list.
4. When improving a skill, explain what changed and why in the PR, ideally with a before/after example.

### Pull request guidelines
- One change per PR; title like `feat(skill-name): ...`, `fix(skill-name): ...`, `docs: ...`.
- Do not copy copyrighted material; link to external projects instead.
- By contributing you agree your work is released under the MIT License.

### Privacy
Never include private or sensitive data: real names, account handles, contact details, local file paths, photos of real people, unpublished internal material, or any API keys, tokens or passwords. PRs containing such data will not be merged.
