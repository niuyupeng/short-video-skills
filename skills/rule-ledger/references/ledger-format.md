# 账本格式

```
| id | 生效日期 | 键 | 值 | 来源 | 旧值写法 |
|---|---|---|---|---|---|
| R7 | 2026-03-02 | 视频画幅 | 16:9 | 负责人书面，周会纪要 | |
```

- **id**：只增不改，R1、R2…
- **生效日期**：ISO 格式 `YYYY-MM-DD`，按定规则的人所在时区。
- **键**：名词短语，一件事一个键。建议先建键表，新规则先查键表再记。
- **值**：尽量写成可比较的形式（`1.2s`、`16:9`、`4 LU`）。
- **来源**：谁定的、在哪里说的。不写私人联系方式。
- **旧值写法**：逗号分隔，只在被取代的那条上填。

## 键的命名
| 好 | 不好 | 原因 |
|---|---|---|
| 片尾时长上限 | 片尾 | 太宽，会和「片尾内容」混 |
| 人声高于配乐 | 音量 | 不知道是哪两个的差 |
| 视频画幅 | 竖版还是横版 | 键里不放值 |
