# 样例 / Example：content-growth-ops

> 改写自团队一条真实视频的一稿多投草稿。账号名、本机路径、活动话题已去掉。所有文字仍是**草稿**，由负责人审批发布。
> Adapted from a real cross-post draft; account names, local paths and campaign tags removed. Drafts only.

## 输入 / Input
「把这条改成 B 站和小红书版」——原片：43 秒横版 16:9，主题「刷完牙只吐别漱」，出处 NHS。

## 输出 / Output
**bili.txt**
```
标题：刷完牙马上漱口，可能白刷了？牙膏里的氟被冲走了｜NHS 建议
分区：知识 → 健康
标签：科普, 口腔健康, 刷牙, 牙膏, 氟, 防蛀牙, 健康
简介：……英国国家医疗服务体系（NHS）建议：刷牙后把牙膏沫吐掉就好，不要马上用水漱口……出处：NHS「How to keep your teeth clean」。
置顶评论：视频里没说的一点：漱口水也一样，就算是含氟的，NHS 也建议别在刷完牙马上用，换个时间（比如午饭后）再用。
声明：该视频使用人工智能合成技术
封面：16:9 + 4:3
```
**xhs.txt**
```
标题：刷完牙别急漱口！吐掉就好
正文：📖 出处：英国 NHS … 🧪 为什么 … ✅ 正确做法：1. 吐掉牙膏沫 2. 不马上用清水漱 3. 漱口水换个时间用
话题：#口腔健康 #刷牙 #护牙 #防蛀牙 #涨知识 #健康生活
声明：内容由AI生成 ｜ 封面 3:4（视频仍为 16:9）
STATUS: DRAFT – awaiting approval
```

**这个样例展示了什么**：事实与原片完全一致，只换标题长度、语气、话题和封面比例；每个平台都勾 AI 声明；首评补一条有出处的新信息，而不是求赞。
