# 样例 / Example：life-tip-producer

> 改写自团队一条真实的生活小招脚本（审核后版本的结构）。账号名、吉祥物、配音设定已去掉；研究数字以审核通过的原文为准。
> Adapted from a real life-tip script (post-review structure). Account, mascot and voice settings removed; numbers as verified.

## 输入 / Input
「做一条生活小招：不好意思开口求人」

## 输出 / Output（节选）
选题门槛：常见痛点 ✅ 今晚能试 ✅ 有一手来源（Flynn & Lake 2008；Zhao & Epley 2022）✅ 非医疗建议 ✅

```
0–3s   钩子：想找人帮个忙，你是直接开口，还是打了又删？（首帧：输入框光标闪）
3–12s  场景：实验让大学生去校园里找陌生人填问卷。
12–28s 为什么：大家猜要问 20 多个人，实际 10 个左右就够了（填问卷实验）。
       被帮的人心情比你想的更好，也没那么觉得被打扰。
28–45s 今晚就试（标为建议）：我的建议是——把事情说具体，说清楚要多久，比如「帮我看一下这段，五分钟就行」。
45–55s 回扣 + 互动：A 能自己扛就不麻烦人 / B 该开口就开口？
```
交付包：`video.mp4`（16:9）、`cover_4x3` + `cover_3x4`、`sources.md`、审核结论。

**这个样例展示了什么**：一个机制、一个可做的小招；论文没测过的部分明确说「我的建议是」，和研究结论分开。
