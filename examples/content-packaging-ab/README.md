# 样例 / Example：content-packaging-ab

> 改写自团队真实的一批包装方案（只出文案和构图，没出图、没发布）。账号名、活动标题前缀已去掉。未附任何效果数据——赢家日志在拿到后台数据前保持「待数据」。
> Adapted from a real packaging batch. Account names and campaign prefixes removed. No performance data: the win log stays "pending" until real data arrives.

## 输入 / Input
「给这条片子出三版标题封面」——片子：刷完牙马上漱口，会把牙膏里的氟冲走（出处：英国 NHS「How to keep your teeth clean」）。

## 输出 / Output
### 标题（每版一个杠杆）
| 版 | 标题 | 杠杆 |
|---|---|---|
| A | 刷完牙马上漱口？这一漱，可能白刷了 | 反常识 |
| B | 刷牙后只吐别漱：牙膏里最有用的东西，被你冲走了 | 具体场景 |
| C | 刷完牙漱三遍才舒服？英国医生说：吐掉就行 | 出处 |

### 封面（横 4:3 为主 + 竖 3:4）
每个比例 A/B/C 三版，只换一个变量（道具特写 / 情绪 / 大字排版）；大字 ≤11 字，25% 缩略图可读。

### 赢家日志
| 日期 | 片 | 元素 | A | B | 指标 | 赢家 |
|---|---|---|---|---|---|---|
| — | 漱口 | 标题 | A | B | 待数据 | 待数据 |

**这个样例展示了什么**：三版标题各用不同杠杆，而不是同义改写；没有数据就不判输赢。
