# 样例 / Example：cover-top-tier

> 改写自团队一份真实的封面规格单。原方案里出镜真人的部分已去掉（真人照片不进公开仓库）。
> Adapted from a real cover spec; the on-camera person element was removed (no real-person photos in this repo).

## 输入 / Input
「按顶级标准做封面」——片子：热水洗手并不比冷水洗得更干净（出处：2017 年《Journal of Food Protection》，比较 15.6℃、26℃、38℃ 三种水温）。

## 输出 / Output
| 项 | 横 4:3（1440×1080，主） | 竖 3:4（1080×1440） |
|---|---|---|
| 大字 | 冷热一样净（5 字，高亮「一样」） | 同左，两行 |
| 主体 | 水龙头 + 肥皂泡手部特写，实物占 60% | 同一场景竖构图 |
| 文字区 | x≈260–1660（1920 宽基准） | y≈280–1640，字高 ≈16% |
| 禁止 | 纯渐变底、徽章堆叠、AI 生成的乱码字 | 同左 |
| 自检 | 缩到 25% 仍能读出大字 | 同左；底部信息栏不放字 |

交付：`cover_4x3.png` + `cover_3x4.png`，每个位置只交一个终稿。

**这个样例展示了什么**：先出无字底图，再用字体叠中文，避免 AI 乱码字；横竖两版都给，不只出一种。
