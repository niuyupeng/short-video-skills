# 示例：reference-first-script

> 题目是为演示自编的中性题目（牛顿与苹果的公开轶事），不来自任何团队的稿子。下面的“改前/改后”是为演示规则而写的示意，**不含任何播放或效果数据**；评分栏只演示格式，不是实测结果。

**用户说**：照着这条参考片的感觉，写“牛顿为什么没被苹果砸傻”。

## 第 1 步：拆参考（节选）
| 项 | 记录 |
|---|---|
| 钩子 | 0 秒直接抛一个荒诞问题【观察到的】 |
| 反转 | 第一个反转很早出现【观察到的】；最响的笑点在中段被放大【推断的，参考无音轨】 |
| 备注 | 参考无音轨 → 节奏、笑点密度为推断，评分非终审 |

## 第 2 步：常见的坑 → 规则（示意）
| 改前 | 问题（规则#） | 改后 |
|---|---|---|
| 开头先说“其实苹果可能根本没砸到他” | 先给谜底、解释笑话（2） | 0 秒：“牛顿为什么没被苹果砸傻？”；谜底挪到结尾，一句冷收 |
| “他把这件事写进了论文” | 偷换概念：苹果故事是晚年聊天时讲的轶事，不是论文内容（3） | “论文里一个苹果都没有，这是他老了以后跟朋友聊天讲的。” |
| 前面叫“科学家”，后面又叫“果农” | 同一对象称呼不一致（3） | 全文统一叫“牛顿” |
| “苹果一落地，他当场想出了万有引力” | 把后来的回忆说成当场（7） | “他后来回忆说，是看苹果落地想到的。” |
| 6 秒复述前文 | 复述（6） | 压成一句：“苹果掉了，他想了，然后想了二十年。” |
| B：“躲开苹果，让它砸下来” | 选项字面自相矛盾（4） | A：继续坐树下等灵感；B：换棵没果子的树？ |
| 一段 7 秒没有笑点 | 笑点密度（5） | 给“我”加一个捂头的反应镜头 |

## 第 3 步：评分输出格式（示意）
```
总分 _/50  结论: 小改   （及格线 40 为默认值，可以按自己团队调整）
| 时间 | 原句 | 问题 | 改句 |
本次是否终审: 否（参考无音轨）
```
